## Ограничения обмена

Документация SM10 Interface description V1.0 указывает отсутствие ответов для collecting/group commands. Ожидание ответа должно зависеть от типа команды. Отсутствие ACK не является общим признаком неисполнения команды, автоматические повторы недопустимы.

Прекращение отправки команд при ошибке не гарантирует физическую остановку уже движущейся оси. Аппаратный останов и поведение при потере связи в этой проверке не тестировались.

После первой ошибки обмен был остановлен. Последующее чтение и его результат описаны в обновлении выше.
