# Перенос на Python — обновлено 2 октября 2026

Интерфейс и его внешний вид остаются WPF/C#. По умолчанию `MotionBackend` в
`devices.json` равен `python`; отсутствие ключа в старой конфигурации также выбирает Python.

## Что работает в Python

`GUI/PythonBackend/sm10.py` содержит операции драйвера SM-10: чтение статуса,
счётчиков C1/C2, разбор координат и аппаратного концевика, абсолютные и относительные
перемещения, выбор Fast/Slow, упаковку параметров команд, проверку целей.
Также перенесены расчёт прямых/обратных связей осей, целей связанных перемещений,
проверка направления относительно концевика, преобразование введённой цели C2 в C1
по свежим координатам и симулятор позиционера.

`motion.py` — основной контроллер: резервирование осей, проверка всей связки до
первой команды, отправка движений, опрос, обработка обратной связи, лимитов, отпускания
клавиши, таймаутов и аварийной блокировки. `jogging.py` задаёт L/M/H и объединяет
нажатые клавиши. `links.py`, `limits.py`, `coordinates.py` содержат соответствующие
функции. C# `MotionService` теперь передаёт операции этому контроллеру, а не выполняет
собственный алгоритм параллельно с Python.

**Коллегам:** [инструкция по изменению функций без пересборки C#](../GUI/PythonBackend/README.md).
Эта инструкция и тесты поставляются в папке `PythonBackend` рядом с GUI.exe.

## Что остаётся в C#

WPF, получение клавиатурных событий и таймер UI, владение физическим портом, камера,
KERN SDK, DirectShow, запись встроенным FFmpeg. Старый ASCII-драйвер и расширенная
консоль полного каталога SM-10 остаются C#; их поведение не менялось.

Общий COM-порт, построение и проверка кадров/CRC, политика ACK/no-ACK, арбитраж
запросов и аварийный Stop также остаются в C#. C# дополнительно проверяет разрешение
движения, принадлежность физических осей и диапазон отправляемой float-координаты.
Python не имеет прямого доступа к порту. Это позволяет отправить Stop при зависании
или завершении Python. Решения о лимитах, связках, потере обратной связи и обычной
остановке выполняются в Python; независимый C#-контур останавливает устройства при
падении или зависании Python-процесса. Исходный алгоритм C# оставлен только для отката
в `LegacyMotionService` и не вызывается в Python-режиме.

Перед каждой командой контроллеру выдерживается **минимум 2 мс внутри общей очереди
COM-порта**: чтение, движение, команды без ACK, обычный и аварийный Stop. Это также
действует для расширенной консоли и C#-режима. Планировщик Windows может удлинить
паузу; она не сокращается ниже 2 мс. Прежняя выдержка после Stop остаётся отдельно.

## Запуск и сборка

При запуске GUI создаётся основной Python-контроллер движения. Каждая подключённая
логическая группа также запускает свой скрытый Python-процесс драйвера.
Обе группы по-прежнему используют один сериализованный COM-транспорт. Связь с Python —
JSON Lines по приватным stdin/stdout; сетевого сервера нет. Драйверы завершаются при
Disconnect, основной процесс — при закрытии приложения. После аварии необходимо
отключить и снова подключить все группы; незавершённые движения не повторяются.
Поколения подключений отсекают запоздалые команды и ответы предыдущего подключения.

CPython 3.13.15 включён в `GUI/ThirdParty/python`, его исходная лицензия сохранена.
`GUI.csproj` копирует runtime и Python-код в Debug/Release и publish. На другом Windows
x64 надо копировать **всю папку `artifacts/LNscope`**, запускать `GUI.exe`.
Отдельные Python, .NET и FFmpeg для опубликованной сборки не нужны. Драйверы камеры,
KERN SDK и USB/COM остаются требованиями оборудования, как до переноса.

Сборка: `./publish.ps1`. Проверка C#/IPC: `./run.ps1 -Check`.
Проверка чистой Python-логики:

```powershell
./GUI/ThirdParty/python/python.exe -I -X utf8 ./GUI.SmokeTests/python_checks.py
./GUI/ThirdParty/python/python.exe -I -X utf8 ./GUI/PythonBackend/check.py
```

Тесты не обращаются к реальным портам. Они проверяют координаты/адреса, связанные
цели, Fast/Slow, отказ до первой команды при лимите ведомой оси, Stop обеих групп
при лимите, убийстве worker и таймауте, запрет повторного движения, переподключение,
работу при пустом PATH, GUI и создание/декодирование MP4.
Также проверяются авария основного Python-контроллера, ручное восстановление после неё,
минимальная пауза 2 мс и изменение поведения после редактирования Python без C#-сборки.
Debug и Release собраны без предупреждений. Готовый `artifacts/LNscope/GUI.exe`
открыт и проверен через интерфейс: Connect симулятора, шаг X с 0 до 10 мкм,
Disconnect. Основные XAML-файлы совпадают с резервной копией; сохранённые профили
Debug и опубликованной сборки также совпадают побайтно.
Проверка реального движения после миграции и запуск на отдельном чистом ПК пока
не выполнялись. Python не меняет сохранённые карты осей, пределы и MotionEnabled.
