# Подключение установки

По фотографиям в соседней папке `Setup_docs`: камера KERN ODC 825 (USB 2.0), пульт L&N SM-10 touch compact. По фотографиям нельзя достоверно определить соответствие физических каналов осям X/Y/Z/D.

29.09.2026 карта текущей установки установлена сопоставлением ответов контроллера со всеми шестью координатами, сообщёнными пользователем с пульта: **stage X/Y/Z = 1/2/3; manipulator X/Y/Z = 7/8/9**. Пульт показывает **counter 2** (0131), а не counter 1 (0101). Для обеих групп локального профиля включён `DisplayUserCoordinates`. Основная координата и поле Target используют counter 2; C1 показывается отдельно. Перед Go заново читаются оба счётчика и вычисляется `targetC1 = targetShown + C1 - C2`; аппаратный API, программные пределы и связки продолжают работать в C1. Относительный шаг не зависит от смещения нуля. Пределы автоматически не расширяются: текущие C1 некоторых осей лежат за ранее заданными пределами, и движение может быть отклонено.

## В приложении

Поведение красной индикации концевиков, общей остановки и режимов L/M/H описано в [LIMITS_AND_JOG.md](LIMITS_AND_JOG.md). Состояние аппаратных концевиков читается с устройства; численные программные пределы остаются отдельной настройкой.

1. Откройте **Hardware setup**, нажмите **Refresh devices**. Обновление списка не включает видеопоток и не посылает команды движения.
2. Выберите пресет **KERN ODC 825 + L&N SM-10**. Он задаёт типы драйверов; номера осей в нём — предложения, требующие проверки. Движение выключено, пределы не заданы.
3. Для KERN выберите **KERN / MicroscopeVIS** и **KERN ODC825**. Для UVC-камер доступен Windows USB / DirectShow. При Apply драйвер определяется по выбранному устройству. Разрешения читаются после Connect. FPS = 0 снимает программное ограничение; положительное значение задаёт верхний предел, реальная частота зависит от камеры и экспозиции.
4. Для вашей общей коробки включите **Stage and manipulator share one controller / cable** и выберите один **Controller COM port**. Пресет SM-10 включает этот вариант. Приложение разделяет одно последовательное соединение между группами осей. Адреса физических осей не должны повторяться между группами. Для разных контроллеров снимите флажок и задайте отдельные порты.
5. Нажмите Apply. Настройки сохраняются рядом с приложением в `devices.json`; подключения автоматически не запускаются. Connect у SM-10 читает позиции и статус без движения, homing и включения моторов.
6. Проверьте по установке номера осей, направления и допустимые координаты в микрометрах. Введите конечные Min/Max и только затем включите разрешение движения. Это программные пределы, зависящие от системы координат контроллера.

Перед открытием настроек отключите группы манипулятора кнопкой Disconnect. При применении настроек поток камеры и запись корректно завершаются.

## Камеры и USB

Драйвер `windows-dshow` работает с UVC/DirectShow-камерами. Подключённая KERN ODC825 (VID 0547 / PID F510) работает через WinUSB и не появляется в DirectShow. Для неё реализован `kern-native`, использующий установленную библиотеку `C:\Program Files\KERN&SOHN\MicroscopeVIS2.0Pro\x64\kerncam.dll` (x86 для 32-битного процесса). На другом ПК требуется установить MicroscopeVIS2.0Pro; эта библиотека не входит в дистрибутив LNscope. Закройте MicroscopeVIS перед Connect, чтобы освободить камеру. Смена драйвера Windows не нужна.

Для проверенного контроллера COM3 включён `AllowLegacyReplyChecksum`: его ответы заканчиваются `BBBB` вместо вычисляемой CRC. Флажок есть в Hardware setup отдельно у каждой группы; группы общего порта должны иметь одинаковое значение. По умолчанию совместимость выключена. Команда, длина, структура и допустимость значений ответа продолжают проверяться; целостность данных с фиксированным `BBBB` проверить невозможно. Настоящие CRC также принимаются, другие неверные CRC отвергаются.

Официальные параметры ODC 825: 2592×1944 до 7 fps, 1296×972 до 28 fps, 648×486 до 101 fps. Приложение использует режимы, реально объявленные установленным драйвером. Источник: [KERN technical data](https://www.kern-sohn.com/data/produktdatenauszug/Technische-Datenblaetter/TD_ODC-825_en.pdf).

FFmpeg включён в дистрибутив. Отдельная установка и выбор EXE не нужны. Переносите всю папку `artifacts/LNscope`, а не один GUI.exe. Экспозиция и усиление через универсальный драйвер пока не реализованы.

Поле Frame rate доступно до подключения. Введите 0 (максимальная частота выбранного режима) либо положительное число; Enter, Tab или уход из поля сохраняют значение. Для Windows-камеры изменение во время потока применяется после Stop live → Start live. Введённое значение сохраняется отдельно от фактического FPS, который ограничен режимом камеры; запись использует частоту текущего захвата. Изменение поля во время записи не меняет временную шкалу текущего файла.

## SM-10

Новый `sm10-binary` использует 115200, 8N1, команды положения 0101/0131, статуса 0120, движения 0048/0049 и останова 00FF. CRC-16/1021 с начальным нулём считается по данным. Числа float передаются little-endian, код команды и CRC — big-endian. Движения автоматически не повторяются после таймаута.

Основание: `CD-SM10V20-TAS7-TAS10/SM10 Interface description V1.0.pdf` и немецкий оригинал `SM10 Beschreibung des seriellen Protokolls V1.0.pdf` в Setup_docs. В английском описании 8-байтового статуса пропущен один reserved-байт; использована структура немецкого оригинала, стр. 18: признак движения в байте с индексом 6. Старый NextLevel ASCII оставлен отдельным драйвером и не выбран для SM-10.

При ошибке обмена соединение блокируется до отключения всех групп этого COM и повторного подключения. Автоматического переключения протокола нет. Если контроллер настроен иначе, нужно проверить его режим по документации.

## Проверено и осталось

28 сентября 2026: сборка и автоматические проверки прошли. Проверены CRC/пакеты, разбор камер/режимов, подключение без движения на тестовой шине, ограничения целей, адресация осей, команда Stop, повторное подключение, запись и декодирование MP4 без FFmpeg в PATH.

При локальном обнаружении KERN и COM-порты не найдены; доступны USB2.0 HD UVC WebCam и OBS Virtual Camera. Реальные захват KERN, обмен SM-10, направление осей, останов, обрыв связи и длительная запись требуют проверки с подключённой установкой. Тесты не двигали оборудование.

Интерфейсы `ICamera` и `IPositioner` отделяют GUI от оборудования. Для другой камеры с собственным SDK или другого манипулятора добавляется драйвер, сохраняющий эти интерфейсы; универсальный USB не заменяет протокол производителя.
